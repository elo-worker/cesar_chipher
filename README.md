# Шифр Цезаря (Caesar Cipher) на Python

**Консольный скрипт для шифрования и дешифрования текста** методом Цезаря. Программа работает в интерактивном режиме через терминал, автоматически определяя направление сдвига на основе выбора пользователя.

## 🚀 Возможности

*   **Два языка:** полная поддержка английского (`en`) и русского (`rus`) алфавитов.
*   **Регистронезависимость:** сохраняет исходный регистр букв (строчные остаются строчными, заглавные — заглавными).
*   **Сохранение символов:** знаки препинания, цифры, пробелы и спецсимволы не шифруются и остаются на своих местах.
*   **Интерактивный CLI:** удобный ввод данных через стандартный `input()`.

## 🛠️ Требования

Для запуска скрипта вам понадобится установленный интерпретатор Python:
*   **Python 3.6 или выше** (используются только встроенные библиотеки, устанавливать дополнительные пакеты не нужно).

## 💻 Установка и запуск

1. Склонируйте этот репозиторий к себе на компьютер:
   ```bash
   git clone https://github.com
   ```

2. Перейдите в папку с проектом:
   ```bash
   cd ИМЯ_РЕПОЗИТОРИЯ
   ```

3. Запустите скрипт:
   ```bash
   python main.py
   ```

## 📖 Пример использования

После запуска программа поочередно запросит параметры в консоли:

```text
Введите текст: Привет, Мир!
Вы хотите зашифровать или расшифровать сообщение?(з/р) з
Какой алфавит используем?(rus/en) rus
Введите шаг сдвига: 2
```

**Результат в консоли:**
```text
Рстгжф, Нкт!
```
